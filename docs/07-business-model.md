# Business Model (Free / Pro / Enterprise)

Commercial packaging should not drive Phase 1 architecture, but entitlement hooks should remain possible.

## Free

Deliberately useful but constrained:

- Limited AI messages
- Limited document uploads
- Basic legal research
- Basic workspace
- Limited memory
- Limited agents
- Limited document processing

## Pro

- Larger context
- More documents
- Advanced agents
- Advanced research
- Long-term matter memory
- Multi-model routing
- Advanced document AI
- Collaboration
- Priority processing
- More sophisticated workflows

## Firm / Enterprise

- SSO
- RBAC
- Audit logs
- Dedicated environments
- Data residency options
- Custom retention
- Administrative controls
- Enterprise security

## Phase 1 stance

- No full billing system required to complete Phase 1
- Design usage counters / plan fields so Free vs Pro limits can be enforced later
- Do not block foundation work on subscription infrastructure
